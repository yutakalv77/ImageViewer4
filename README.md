# ImageViewer4

**大容量フォルダも一瞬で開く。漫画・イラスト・写真を思い通りに楽しむ、次世代の高速デスクトップ画像ビューアー。**

Tauri (Rust) + React + TypeScript で構築された、圧倒的な描画パフォーマンスと使いやすさを追求したモダンな画像ギャラリー＆ビューアーです。数千〜数万枚の画像や大量のサブフォルダを抱える巨大ディレクトリでも、メモリを圧迫することなく瞬時に表示・快適に閲覧できます。

---

## 🌟 Windows ストア向け プロモーション概要

### キャッチコピー
> **「重いフォルダも、もう待たない。」**  
> 爆速表示 × 漫画見開き × Everything検索連携。あなたのPCに眠る膨大なコレクションを、最速かつ最高のアート体験へ。

### 本アプリの売り文句・特長（Key Highlights）

1. **⚡ 数万枚でもメモリを喰わない「仮想スクロール（Virtual Grid）」**
   - 画面内に表示されるカードのみをスマートに描画する仮想グリッド技術を搭載。1万枚を超える画像や大量のサブフォルダがあっても、スクロールのカクつきやメモリ不足とは無縁です。
2. **🚀 Windows ネイティブの力を極限まで引き出す「ハイブリッドサムネイルエンジン」**
   - Windows シェルサムネイル API（`IShellItemImageFactory`）と独自開発の Rust 高速キャッシュ（FNV-1a ハッシュ管理）を融合。フォルダを開いた瞬間にサムネイルが $O(1)$ で復元され、2回目以降の表示速度はほぼ 0 ミリ秒です。
3. **📁 フォルダの深層まで見通す「オンデマンド・ストリーミング」**
   - サブフォルダ内の代表画像（直下〜最大5階層）を自動探索し、アルバムカバーとして非同期に遅延取得。フォルダを開く前の段階で中身が一目でわかります。
4. **📖 漫画・同人誌・電子書籍に特化した「見開きビューアー」**
   - 日本の漫画に必須の「右綴じ」、洋書や雑誌向けの「左綴じ」にワンクリックで対応。さらに「最初の1枚を表紙として単独表示」する自動レイアウト機能を備え、作品の構成を崩さずに鑑賞できます。
5. **🔍 超高速ファイル検索「Everything」とのダイレクト連携**
   - Windows ユーザーに絶大な人気を誇る Voidtools「Everything」とシームレスに連動。ドライブ全体に散らばる膨大なアルバムやフォルダを一瞬で検索し、その場でギャラリー展開できます。
6. **🔒 安心の完全ローカル動作 ＆ ポータブル保存設計**
   - 外部サーバーへの画像アップロードやテレメトリ通信は一切なし。お気に入りや履歴データの保存先フォルダも自由に指定できるため、外付けSSDやUSBメモリ、NAS環境でも快適に運用可能です。
7. **🎨 写真・アートが映える洗練されたダークモダンデザイン**
   - 作品鑑賞の邪魔をしないブラックベースのUI。ギャラリーとビューアーの境界ドラッグリサイズ、Ctrl＋マウスホイールによる滑らかなサムネイル拡縮、全画面没入モードを搭載。

## 📋 網羅的機能一覧

### 1. ギャラリー＆ブラウジング機能
- **仮想スクロールグリッド（Virtual Grid）**:
  - 表示領域に応じた動的レンダリングにより、数万エントリでも 60fps〜120fps の滑らかなスクロールを実現。
- **サムネイル拡縮（ズーム）**:
  - `Ctrl + マウスホイール` またはメニュー操作で、サムネイルサイズを無段階・スムーズに拡大縮小（100%リセット対応）。
- **多彩なソート（並び替え）**:
  - 名前順、更新日時順、作成日時順、ファイルサイズ順に対応。
  - 自然順ソート（数値の連続順）、昇順・降順切り替え、フォルダーの先頭優先表示に対応。
- **パンくずリスト＆アドレスバー**:
  - パスの階層を直感的にクリック移動可能。直接パス入力での移動にも対応。
- **ナビゲーション履歴**:
  - 「戻る」「進む」「上の階層へ」のブラウザ風操作に対応。階層移動時のスクロール位置を自動記憶・完全復元。
- **コンテキストメニュー（右クリック）**:
  - 「エクスプローラーで表示」「ファイルパスのコピー」「名前の変更（インライン編集対応）」などのクイック操作。
- **ドラッグ＆ドロップ対応**:
  - デスクトップやエクスプローラーからフォルダを直接ドラッグ＆ドロップして即時ブラウズ。

### 2. マルチモード画像ビューアー（コミック＆写真鑑賞）
- **単一表示モード（Single View）**:
  - 高精細な写真を1枚ずつじっくり鑑賞。
- **見開き表示モード（Spread View）**:
  - 2枚の画像を左右に並べて同時に表示。
  - **右綴じ（RTL）**: 和書・日本の漫画に最適化。
  - **左綴じ（LTR）**: 洋書・海外コミック・雑誌に最適化。
  - **表紙モード（First page is cover）**: 1ページ目を単独表示し、2ページ目以降を見開きペアリング。
- **フルスクリーン表示（F11 / ダブルクリック）**:
  - ウィンドウ枠をなくし、画面いっぱいに広がる没入読書。操作バーの自動隠蔽に対応。
- **画面自動フィット＆スケーリング**:
  - ウィンドウサイズに合わせて自動縮小・アスペクト比維持。
- **キーボード＆マウス操作の完全サポート**:
  - 矢印キー（← / →）、マウスホイールによる直感的なページめくり。右綴じ/左綴じに応じた送り方向の自動反転。
- **ページ番号表示のカスタマイズ**:
  - 右下、中央下、非表示など、お好みの表示位置を選択可能。

### 3. スライドショー機能
- **自動ページ送り**:
  - 手放しで写真やコミックを連続鑑賞。
- **高精度インターバル設定**:
  - 1秒〜9秒のプリセットに加え、0.1秒単位（0.1秒〜99.9秒）でのミリ秒精度カスタム時間設定が可能。
- **ループ再生オプション**:
  - フォルダ末尾に到達した際、先頭に戻ってエンドレス再生するトグル設定。

### 4. 検索機能
- **ローカルフォルダ再帰検索**:
  - 現在のフォルダ階層下にあるサブフォルダを高速にインクリメンタル検索。
- **Everything 連携検索（Windows）**:
  - Voidtools `es.exe` CLI と連携し、数秒で数百万ファイルの中から目的のフォルダを検索・抽出。
  - CLIパスのカスタム指定、最大取得件数の調整、常駐ステータスの自動検知に対応。

### 5. お気に入り・履歴・キャッシュ管理
- **お気に入り（ブックマーク）**:
  - よく閲覧するフォルダをワンクリックで登録。カード上の「⭐」バッジ表示、専用バーからの即座ジャンプ。
- **閲覧履歴**:
  - 最近アクセスしたフォルダを自動記録。保持期間（1日/7日/30日/無期限/無効）をカスタマイズ可能。
- **キャッシュ容量の可視化＆ワンクリッククリア**:
  - 生成されたサムネイルの合計ディスク消費量を設定画面でリアルタイム表示。確認ダイアログ付きのワンクリック削除機能を完備。
- **保存先ストレージ変更（ポータブル対応）**:
  - 設定データ・履歴・お気に入りの保存先を任意のディレクトリ（USBメモリや共有ドライブなど）に変更可能。

### 6. 画像詳細プロパティ診断（Image Info）
- **画像の高度なメタデータを瞬時に解析・表示**:
  - ファイル形式（JPEG, PNG, WebP, AVIF, TIFF, BMP, SVG 等）
  - 画像解像度（幅 × 高さ、アスペクト比）
  - ビット深度（bpp / カラー深度）
  - 正確なファイルサイズ（バイト / KB / MB）
  - 総使用色数（ユニークカラー数の自動/手動算出）
  - 更新日時、フォルダ内でのインデックス番号
  - デコード＆読み込み所要時間（ミリ秒表示）

### 7. 幅広い対応フォーマット
- **ラスター画像**: JPEG (`.jpg`, `.jpeg`, `.jfif`), PNG, WebP, AVIF, BMP, TIFF (`.tif`, `.tiff`), GIF
- **ベクター画像**: SVG（ベクター品質のまま直接レンダリング）
- **アイコン**: ICO

- [Node.js](https://nodejs.org/) (LTS推奨)


## ビルド（配布パッケージの出力）

### 単体 exe ファイルの出力（ポータブル版）
インストーラーを介さず、単体でそのまま実行できる `.exe` ファイルを出力する場合：

```bash
npm run build:exe
# または
npx tauri build --no-bundle
```

**出力先**:
- `src-tauri/target/release/image-viewer.exe`

※ 出力された `image-viewer.exe` は、フロントエンドリソース（HTML/CSS/JS）がバイナリ内に静的にバンドルされているため、単体で任意の場所に配置してダブルクリックで起動できます。

### インストーラーを含むビルド（MSI / NSIS / Windows Store用）
インストーラー（セットアップ exe や msi）を含めてパッケージングする場合：

```bash
npm run build:app
# または
npm run tauri build
```

**出力先**:
- 単体 exe: `src-tauri/target/release/image-viewer.exe`
- NSIS セットアップ: `src-tauri/target/release/bundle/nsis/image-viewer_0.1.0_x64-setup.exe`

## 開発ガイドライン（実装後のレビュー・リファクタリング方針）

機能追加や改修の実装後は、**必ず以下のレビュー観点に基づいたコードレビューを実施し、必要に応じてリファクタリングを行ってください**。

### レビュー観点

1. **クラス・関数・コンポーネントの責務分離（単一責任の原則: SRP）**
   - 1つのコンポーネントや関数にUI表示、OS・ウィンドウ操作、副作用・イベント監視、データ処理などの複数責務が集中していないか。
   - 共通パターン（クリック外検知、キーボードショートカット、フォーカス管理など）が各所に重複実装されておらず、カスタムフック等に適切に抽出されているか。

2. **純粋関数の抽出とテスト容易性**
   - UIコンポーネント内にパス解析、データ変換、フォーマットなどのビジネスロジックがインラインで埋め込まれていないか。
   - ロジックを副作用のない純粋関数としてユーティリティ等に切り出し、単体テストが整備されているか。

3. **将来の改修に耐えうる拡張性と保守性**
   - 新規機能や項目追加時に、既存コードを大規模に変更せずに済む疎結合な設計になっているか。
   - ハードコードを避け、設定配列や共通インターフェースを活用した変更に強い構造になっているか。

4. **品質検証（テストと型整合性）の担保**
   - 全単体テストがパスすること（`npm test`、および Rust 変更時は `cargo test`）。
   - TypeScript 型チェックおよびビルドがエラーなく通過すること（`npm run build`）。
